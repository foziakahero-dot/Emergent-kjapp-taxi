# KJAPP landing (Next.js 14)

Standalone App Router + Tailwind preview of the marketing landing. Existing marketing-web Vite application and partner routes are untouched. Run `npm ci && npm run build && npm run dev` in this directory. Configure WAITLIST_WEBHOOK_URL (HTTPS durable receiver) and WAITLIST_WEBHOOK_SECRET on the server; otherwise the form reports an honest 503 and never claims a signup was saved. The buyer-facing social proof numbers and queue rank requested in the brief are intentionally omitted pending actual source data. The supplied tariff numbers are explicitly marked as illustrative until pricing is approved. Confirm the legal registration number before displaying it. Assets were reused from marketing-web/public/assets/figma; Next Image negotiates AVIF/WebP for cars.
