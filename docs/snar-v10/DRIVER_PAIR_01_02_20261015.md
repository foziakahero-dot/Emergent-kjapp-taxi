Source: the Fleet v2 ZIP supplied by the user, SHA-256 recorded in `reference/fleet-v2-20261014/manifest.json`. This continues the same implementation branch after the user approved publication. It does not require another source upload.

## Changes

- Splash uses the source's fixed inverse background, Driver label and centered 96×96 mark, including while signed out. The real login action is anchored separately so it no longer displaces the source lockup.
- Mark entrance uses the source's 320 ms spring curve. Wordmark enters from 8 px over 210 ms after 120 ms. Reduced motion still suppresses the entrance and light trace.
- Wordmark line height is 28 px, matching the rendered original. At the 370×824 reference viewport, both source and rendered native component place the mark at x=137, y=329.
- Login uses the shared primary action, retaining the source's 58 px height, 16 px radius, palette and primary shadow. The actual password/provider busy lock and account/legal/identity gates are unchanged.

## Intentional contract adaptations

The prototype's hardcoded phone number, BankID action and automatic approval navigation are not production authentication. The app retains working email/phone plus password, Google and native Apple sign-in; BankID remains excluded. The extra password/provider fields therefore differ from the prototype. No fake support number or automatic login was introduced.
