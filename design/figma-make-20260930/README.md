# Figma Make source reference

Exact source files from the supplied 30 September 2026 export. These are reference files and are not compiled into either native app. The export predates the current live file; live-file parity has not been confirmed.

Customer/Driver production data, credentials, routing and trip state come from KJAPP APIs. The source sample users, vehicles, estimates, automatic trip simulation and demo approval are not production behavior.

The source icon uses the S ribbon for both store variants. App names, identifiers and deep links retain the existing KJAPP identity. SVG source and generated platform assets are kept in each app assets directory.
